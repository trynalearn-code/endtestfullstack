# Online School Classroom

## Description

Students can sign in online to their dashboard in order to sign up and take classes for school. It's like the best school in the world.
Additionally, there are admin accounts for special access.

instalation instructions:
npm create vite@latest .
npm install express dotenv
npm install react-router-dom
the program can be run with npm run dev

the PORT is hidden in the env. You can run on your own port
